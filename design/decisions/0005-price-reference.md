# 0005: 出品時に「相場」を出さず、同カテゴリの出品を参考として並べる

- 状態: 決定
- 対象画面: `SellPage`
- 前提: [`journey-map.md`](../journey-map.md) 出品 2（相場観）

## 問題

出品ジャーニー 2 で「いくらで出すか」に迷う。出品フォームで同カテゴリの
価格が見られれば決めやすい。

素直な実装は「このカテゴリの相場は ◯◯ 円です」と 1 つの数字を出すこと。
平均・中央値・レンジのどれを出すかという選択がある。

## 決定

**「相場」という言葉を使わず、数字を 1 つに丸めない。**
同カテゴリで出品中のものを、価格つきでそのまま数件並べる。
見出しは「参考: 同じカテゴリの出品」。

件数が 3 件未満のときは、**件数が少ない旨を明示する**。

## 理由

現在のカタログはカテゴリあたり **1〜2 件**しかない。

| カテゴリ | 件数 |
| -------- | ---- |
| カメラ / 食器 | 2 |
| PC周辺機器 / 本 / 楽器 / アウトドア | 1 |

**1 件から「相場」は出せない。** 平均も中央値も、その 1 件の価格そのものに
なる。それを「相場」と表示すると、根拠のない数字を根拠があるかのように
見せることになる。

これは [`0003`](0003-analytics-scope.md) で分析について決めたのと同じ判断。
**言えることの範囲を超えて書かない。** データが増えれば言えることも増えるが、
増えるまでは増えた後の書き方をしない。

### カタログを水増ししない

「カテゴリごとに 10 件あれば相場が出せる」は事実だが、そのために
`LISTINGS` を増やすことはしない。カタログ（画面に出る商品）と分析用データは
別ソースにするという方針（[`0003`](0003-analytics-scope.md) §3）を、
ここでも守る。

## トレードオフとして受け入れたこと

- **「いくらで出すか」の答えにはならない。** 参考情報を出すだけで、
  推奨価格は提示しない。ジャーニー 2 は 🚧 のまま（❌ ではない）
- **同カテゴリが 0 件のとき何も出せない。** その場合はセクションごと出さない
  （空の枠を見せない）

## 実装への制約

- 集計は純粋関数に分離してテストする（`selectCategoryReference`）
- 表示は最大 3 件。多すぎると出品フォームの邪魔になる
- **出品中のものだけ**を対象にする（売却済みは「今出すならいくら」の
  参考にならない）
- 自分の出品は除く（自分の値付けを自分に見せても参考にならない）

## 将来やるなら

売却済みの価格と成約までの日数が溜まれば「この価格帯なら平均 N 日で売れる」
が言える。それは [`0003`](0003-analytics-scope.md) の分析スコープの話で、
合成ログの生成器が要る。
